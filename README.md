# Лабораторная работа 3

Тема: Основы программирования на Python. Вариант 80. Казино

## Описание

Программа представляет собой консольную игру-казино, в которой пользователь делает ставки на чётное или нечётное число. Игра поддерживает управление балансом, подсчёт побед и поражений, проверку допустимости ставок и случайные игровые события. В процессе работы программа постоянно запрашивает команды у пользователя и обновляет состояние игры.

Основные возможности:

- проверка корректности ввода суммы и выбора ставки;
- ведение текущего баланса;
- подсчёт общего числа побед и поражений;
- генерация случайного результата для каждой ставки;
- поддержка специальных событий: джекпот и серия проигрышей.

## Как запустить

1. Откройте терминал в папке проекта.
2. Выполните команду:

   python main.py

   Если Python установлен под именем python3, можно использовать:

   python3 main.py

## Список команд

- `bet <сумма> <even/odd>` — сделать ставку на чётное или нечётное число.
- `balance` — вывести текущий баланс.
- `history` — вывести статистику побед и поражений.
- `help` — вывести список доступных команд.
- `exit` — завершить игру.

## Пример работы

```text
Добро пожаловать в казино «Удача»!
Введите команду: bet 100 even
Результат: odd
Вы проиграли!

```

## Структура проекта

- `main.py` — основной исполняемый файл с логикой игры.
- `casino_data.py` — текстовые сообщения и параметры игровых событий.
- `requirements.txt` — список зависимостей проекта.
