# Лабораторная работа 3

Тема: Основы программирования на Python. Вариант 19. Казино

## Описание

Программа представляет собой консольный симулятор игровой системы в стиле казино. Пользователь может делать ставки на четное или нечетное число, следить за текущим балансом и просматривать статистику побед и поражений.

## Как запустить

1. Откройте терминал в папке проекта.
2. Выполните команду:

   python main.py

   Если Python установлен как `python3`, используйте:

   python3 main.py

## Список команд

- `bet <сумма> <even/odd>` — сделать ставку на чётное или нечётное число.
- `balance` — вывести текущий баланс.
- `history` — показать количество побед и поражений.
- `help` — показать доступные команды.
- `exit` — завершить игру.
